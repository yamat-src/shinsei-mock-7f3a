# 申込Webモック環境（面接用）

IT人材面接の実技課題で使う、架空の申込Webサイトです。
登場する会社・システム・案件・人物・住所・番号はすべて架空であり、実在の事業者とは関係ありません。

## 公開方法（GitHub Pages）

1. GitHubで新しいリポジトリを作る（推測されにくい名前を推奨。例：`shinsei-mock-7f3a`）
2. このフォルダの中身（`index.html` / `files/` / `.nojekyll` / `README.md`）をそのままアップロードする
3. Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `(root)` にして Save
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される
5. 候補者にはこのURLだけを伝える

## 注意

- **面接官コンソール（正解マスタ入り）はこのフォルダに含めないでください。** 面接官のPCでローカルに開いて使います。
- このビルドには正解データ・採点ロジック・管理画面は一切含まれていません（ソースを見ても正解は分かりません）。
- 公開リポジトリにすると誰でも閲覧できます。同じ課題を繰り返し使う場合は、リポジトリ名を変える／ダミーデータを差し替えるなどの対応を検討してください。
